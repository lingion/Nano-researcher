2. 审计通过的三项核心能力

PASS Evidence Integrity

Agent 没有停留在搜索摘要，而是 fetch 官方正文，并把发布主体、时间、文号、金额条款绑定到同一官方来源。

PASS Constraint Sensitivity

Agent 没有把普陀区材料夸大成上海全市政策，也没有把内部预算下达通知包装成公众申请指南。

PASS Noise Suppression

Agent 识别并弃用 shui5.cn 非官方转载/文章站，保留官方来源作为唯一证据链。

4. Golden Fixture 的最低回归断言

Infrastructure 改动后，重跑该 case 时至少应满足以下断言；否则应视为回归失败。

  1. 最终决策应为 stop，而不是卡在 search/fetch 循环。
  2. 最终证据必须包含官方 URL：shpt.gov.cn。
  3. 最终包必须识别发布主体：上海市普陀区卫生健康委员会。
  4. 最终包必须识别文号：普卫健行办〔2026〕1号。
  5. 最终包必须包含多个对象化金额条款，且至少包含普陀区中心医院、普陀区人民医院、普陀区利群医院。
  6. 最终不确定性必须保留：该材料是普陀区区级材料，不是上海全市统一补贴目录。
  7. 最终不确定性必须保留：该材料是预算/补贴下达通知，不是开放申请指南。
  8. shui5.cn 等非官方来源不能进入最终证据链，只能进入 discarded leads 或低优先级线索。
建议：后续不要用该 case 证明 Prompt 更“聪明”，而要用它证明 gateway、provider、fetch、search、trace parse、state update 等基础设施没有破坏 Agent 的既有认知能力。

5. 路线决策

方向 建议 理由
Heavy Prompt 冻结 暂停瘦身与语义补丁 该 case 已证明现有 Prompt 能在真实互联网环境中执行专业证据纪律。
DecisionContext 谨慎 不作为当前必要补丁 过早规则引擎化可能干扰模型对行政边界和实质正文的判断。
Infrastructure 优先 继续加固 provider、gateway、fetch、trace infra 越透明，模型越能发挥已有推理能力。
Regression Suite 扩充 以该 trace 为第一枚 Golden Fixture 用多 case 覆盖区级/市级、指南/预算、官方/转载、搜索/fetch 等边界。

6. 下一步建议

  • 将该 trace 复制或登记为 fixtures/golden/live-audit-shanghai-medical-subsidy-putuo-2026.json。
  • 为上述 8 条最低断言写一个轻量 regression checker。
  • 新增 2-3 个反例 fixture：市级政策、非官方转载诱饵、开放申请指南，以验证边界管理不会只在本 case 上成立。
  • Infrastructure 每次改动后先跑 Golden Fixture，再讨论是否需要 Prompt 变更。
