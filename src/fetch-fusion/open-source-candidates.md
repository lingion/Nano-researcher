# Fetch fusion candidates

This file tracks harvested open-source fetch and extraction candidates.

## Needed capabilities
- stronger local page fetch
- content extraction
- readability/main-body extraction
- browser-assisted fetch when static fetch fails
- redirect/TLS resilience

## Evaluation standard
- must return stronger page evidence than discovery-only search tools
- must expose final URL, title, and main body content
- must be usable locally without reintroducing code-level business rules
